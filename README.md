# VisaCost Hub data

`data.js` holds every fee, funds amount and key date used by the calculators on visacosthub.com.

The VisaCost Hub WordPress plugin reads it daily from:
https://raw.githubusercontent.com/trcportals-droid/visacost-data/main/data.js

It is updated automatically each month. If you edit it by hand, keep the structure and keys the same.
